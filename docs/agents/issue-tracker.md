# Issue tracker: GitHub

Issues and specs for this repo live as GitHub Issues. Use the `gh` CLI for all issue operations.

Create an issue with `gh issue create --title "..." --body "..."`. Read issues with `gh issue view <number> --comments`, list them with `gh issue list`, comment with `gh issue comment <number> --body "..."`, apply labels with `gh issue edit <number> --add-label "..."`, and close them with `gh issue close <number> --comment "..."`.

PRs are not a triage request surface for this repository. The issue tracker is inferred from the `origin` remote, currently `git@github.com:engelyu/cs-note.git`.
